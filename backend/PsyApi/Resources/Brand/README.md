# 🎨 Brand Assets - Logo Instructions

## Logo Placement

Please place your organization logo here with the filename: `SITES-ICON.png`

### Specifications:
- **Format**: PNG with transparency
- **Size**: 200-300px width (maintains aspect ratio)
- **Resolution**: High resolution (300 DPI recommended for print-quality reports)
- **Background**: Transparent
- **Color Mode**: RGB

### Usage in Reports:
The logo will be displayed:
- **Page 1 (Cover)**: Top center, 64-80px height
- Below logo: "منصة التحليل النفسي المتقدم" (Advanced Psychological Analysis Platform)

### Alternative:
If you don't have a logo yet, you can:
1. Place any PNG image here named `SITES-ICON.png`
2. Or the system will skip logo rendering gracefully

### Example File Structure:
```
Resources/
└── Brand/
    ├── SITES-ICON.png          (Main logo - REQUIRED)
    ├── SITES-ICON-DARK.png     (Optional: Dark variant)
    └── README.md               (This file)
```

### Color Recommendations:
The report uses:
- Primary Blue: #1E40AF
- Success Green: #14A44D  
- Warning Orange: #FF8C00
- Error Red: #E53935

Ensure your logo complements these colors or is neutral enough to work with them.
