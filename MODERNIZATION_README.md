## 🚀 **Deployment**

### **Quick Deployment Steps**

```bash
# 1. Install dependencies
cd frontend/user-ui && npm install
cd frontend/admin-ui && npm install

# 2. Build for production
cd frontend/user-ui && npm run build
cd frontend/admin-ui && npm run build

# 3. Test locally
cd frontend/user-ui && npm run preview
cd frontend/admin-ui && npm run preview

# 4. Verify timer functionality
# - Start exam
```
